# 模板库与字体布局编辑器模式

本文是模板库、产品特殊规则和独立字体布局模块的编辑器入口约定。修改入口、初始化规格、左侧面板、保存接口或产品特殊画布时，必须同步更新本文。

## 总体原则

模板库和字体布局模块可以复用同一个 Fabric 编辑器与画布实现，但它们编辑的是不同业务对象，不能共用同一套页面流程或保存逻辑。

| 对比项 | 模板库编辑器 | 字体布局编辑器 |
| --- | --- | --- |
| 编辑对象 | 尺寸模板 | 字体布局模板 |
| 入口 | 模板库产品下的尺寸模板卡片 | 字体布局导航的店铺、产品下的字体布局卡片 |
| 列表 | 尺寸模板卡片列表 | 字体布局卡片列表 |
| 新增入口 | 尺寸模板列表页 | 字体布局列表页 |
| 基本信息 | 尺寸模板的名称、店铺等 | 字体布局的名称、店铺等 |
| 尺寸来源 | 已有尺寸模板详情，或产品规格生成的初始尺寸方案 | 产品接口 `GET /api/v1/products/{id}` 中 `common_spec_values` 的第一个规格 |
| 尺寸编辑 | 完整尺寸方案编辑能力 | 只展示画布与当前初始尺寸的核心数据 |
| 图层 | 尺寸模板及其所应用字体布局的图层 | 当前字体布局自身的 `elements` |
| 保存目标 | 尺寸模板接口 | `font-layout-templates` 字体布局库接口 |

## 模板库打开编辑器

模板库先按产品展示尺寸模板卡片。打开已有卡片时，读取完整尺寸模板详情；点击新增时，根据当前产品生成初始尺寸方案。

模板库编辑器保留：

- 基本信息。
- 完整尺寸方案管理，包括新增、删除、切换和保存规格。
- 背脊计算、页数、纸张厚度及产品需要的其他规格字段。
- 字体布局选择和应用能力，但不在模板编辑器内管理字体布局的新增、重命名、删除等生命周期操作。
- Fabric 画布、图层、素材和导出能力。

普通产品新增尺寸模板时，优先使用产品 `commonSpecValues` 中的规格生成初始尺寸方案。产品没有可用规格时，才使用编辑器默认值。

### 宣誓册产品

宣誓册是模板库编辑器的特殊产品模式，不使用普通封面、背脊、封底规格展示规则。当前约定：

- 初始单位为 `mm`。
- 初始单面宽为 `102.02`。
- 初始单面高为 `140.04`。
- 左右出血为 `58`。
- 上下出血为 `45.97`。
- 背脊宽、背脊出血、最小和最大背脊宽均为 `0`。
- 使用独立的横向、纵向出血展示。
- 跳过普通封面文字安全区自动校正和阻止保存逻辑。

后续若增加其他特殊产品，应通过明确的产品规则判断，并在本节增加对应规格与画布行为；不能通过画布宽高猜测产品类型。

## 字体布局模块打开编辑器

左侧导航中的“字体布局”与“模板库”同级，排列在模板库之后；选择店铺和具体产品后，字体布局模块首先显示该产品的字体布局卡片列表，不直接进入编辑器。

字体布局列表页负责：

- 展示当前产品的字体布局卡片。
- 提供“新增布局”入口。
- 打开已有字体布局。
- 删除字体布局。
- 刷新列表。

新增字体布局先输入字体布局名称。创建成功后进入字体布局编辑器。初始画布使用产品接口中第一个 `common_spec_values` 规格；它只负责提供画布的物理尺寸，不创建一份尺寸模板，也不把浏览器 DOM 尺寸作为设计坐标。

字体布局编辑器只保留以下业务区域：

1. 基本信息：这里是字体布局的基本信息，不是尺寸模板基本信息。
2. 尺寸方案：展示 Fabric 画布、背景填充和当前尺寸核心数据。
3. 图层、素材和属性编辑能力。

字体布局尺寸区域仅展示：

- 单面宽。
- 单面高。
- 出血；有独立横向、纵向出血的特殊产品按产品规则展示。
- 背脊宽。
- 背脊出血。
- 背景填充。

字体布局编辑器不展示规格名称编辑、规格新增删除、页数选项、纸张厚度、最小/最大背脊宽、背脊依据等尺寸模板管理字段。产品有特殊画布结构时，沿用该产品在模板库中的特殊画布结构，但仍遵守字体布局编辑器的精简字段范围。

## 数据和接口边界

### 产品规格

字体布局新增时通过 `GET /api/v1/products/{id}` 获取完整产品数据。初始画布只读取第一个产品规格中的：

```text
unit
sideWidth
sideHeight
bleed
spineWidth
spineBleed
```

产品规格缺失时，页面应明确提示“当前产品没有可用规格”，不应静默采用其他产品或当前 DOM 的宽高。

### 字体布局库列表与详情

- 字体布局列表使用 `GET /api/v1/font-layout-templates?limit=100&offset=0&shop_id={shopId}&product_id={productId}`。
- 打开编辑时使用 `GET /api/v1/font-layout-templates/{id}` 获取完整 Fabric `layers`。
- 新增使用 `POST /api/v1/font-layout-templates`。
- 保存使用 `PATCH /api/v1/font-layout-templates/{id}`，提交完整 `layers`。
- 删除使用 `DELETE /api/v1/font-layout-templates/{id}`。

尺寸模板中的关联字体布局配置属于另一条业务链，才使用 `font-templates` 的详情、尺寸同步和 `elements` 数据；独立字体布局模块不要把两个接口混用。

## 画布与坐标约定

- 两种模式都使用 Fabric 画布。
- 编辑器右侧区域变化只影响缩放和显示，不改变设计坐标。
- 画布物理比例来自产品规格或尺寸模板的单面宽、单面高、出血、背脊宽和背脊出血。
- `reference_canvas.width/height` 以及浏览器 DOM 宽高不能覆盖物理尺寸计算。
- 字体布局保存的是当前字体布局的实际图层数据；辅助尺寸说明、安全线和画布参考文字不是图层，不进入 `elements`。
