# 图片地图编辑器说明

本文记录模板编辑页当前的状态模型、画布计算、产品差异、保存边界和导出限制。代码变更涉及画布或接口时，应同步更新本文。

## 入口与运行环境

- 编辑器入口是 `src/image-map-editor/editor-entry.ts`，模板库通过 `ImageMapEditorTestPage` 挂载。
- 画布使用 Fabric.js 7.4.0。编辑器坐标按 CSS 像素计算，基准为 96 DPI：`in = 96px`、`cm = 96 / 2.54px`、`mm = 96 / 25.4px`。
- 编辑器视口可以缩放，但对象位置保存为 Fabric 场景坐标；切换规格或加载字体布局时，先确定工作区尺寸，再加载对象并适应画布。

## 页面状态

编辑页有三类编辑状态：

- `basicInfo`：所属店铺、模板名称等模板基本信息。
- `sizeSchemes`：规格数组。每项包含显示名称、单位、单面宽高、出血、背脊、页数、纸张厚度等字段。
- `activeSizeSchemeId`：当前选中的规格 ID。

这三项是编辑器状态，不是 Fabric 图层对象。字体布局的 `layers` 才是图层文档，格式固定为：

```json
{
  "objects": [],
  "animations": [],
  "styles": [],
  "dataSources": []
}
```

## 画布尺寸与规格

普通单排画布：

```text
宽 = 单面宽 * 2 + 左右出血 * 2 + 背脊出血 * 2 + 背脊宽
高 = 单面高 + 上下出血 * 2
```

双排画布：

```text
宽 = 单面宽 * 2 + 左右出血 * 2
高 = (单面高 + 上下出血 * 2) * 2 + 行间距
```

当前行间距默认是 `0`。双排是一个画布和一套图层，只是在垂直方向显示两排；双排没有背脊，也不预留背脊宽和背脊出血。

规格数值按照用户选择的 `in/cm/mm` 保存，前端只在切换单位时换算显示值。后端接口接收前端传入的数值，不再次换算。

## 产品安全距离

产品接口返回以下三组安全距离，字段经过 `src/shared/safeDistance.ts` 归一化：

- `coverSafeDistance`：封面
- `spineSafeDistance`：背脊
- `backCoverSafeDistance`：封底

每组包含 `top/right/bottom/left`，单位固定为毫米，与规格当前显示单位无关。进入模板编辑页时，模板库把产品安全距离合并到规格；已有模板优先使用模板或产品接口中的对应值。

编辑器在 Fabric 选择上下文中绘制红色虚线安全框：

- 封面、背脊、封底分别使用自己的四边值。
- 双排只绘制封面和封底安全框，不绘制背脊安全框。
- 毫米值只转换一次为 CSS 像素，再按当前工作区缩放绘制。
- 安全框不是 Fabric 对象，不写入 `printGuides`，也不进入 `propertiesToInclude`。
- 因此主保存、保存规格、保存字体布局、导出 JSON、导出图片和导出 SVG 都不会保存或绘制这层红色安全线。

## 字体布局

- 字体布局列表来自字体布局接口；应用某布局时读取其基础 `layers`。
- 已同步的规格通过规格接口读取独立图层；未同步规格使用基础图层，并提示“当前规格暂无独立图层数据，已使用基础字体布局模板”。
- 切换规格时先确定规格画布（包括 `canvasRows`），再加载对应图层，避免先缩放旧画布造成闪动。
- `canvasRows` 保存在字体布局规格的 `workarea` 数据中。旧数据没有该字段时按单排处理。

## 保存边界

- 模板编辑器保存模板基本字段和完整 `size_options`；保存当前规格时先同步当前字体布局规格图层，再更新尺寸模板。
- 字体布局保存使用完整 `layers` 对象，不支持旧的对象数组格式。
- `workarea` 用于恢复画布尺寸、行数和预览。模板模式下背景填充图的 `src` 不作为模板图层源保存；订单编辑模式按订单模板 JSON 规则处理。
- 安全距离只作为产品/规格运行时配置使用，不能通过新增线条对象的方式持久化。

## 导出行为

所有导出入口都会先执行文字安全区检查：

1. 根据文字中心点判断其所在的封面、背脊、封底和排次。
2. 使用对应产品安全距离计算可用矩形。
3. 若文字带有水平或垂直居中标记，先执行对应居中，再测量边界。
4. 超出时每次将字号减少 `0.5px`，重新计算边界，直到文字完全进入安全区或字号降到最小值。
5. 缩小后的字号回写到 Fabric 对象，因此随后保存的 JSON 也包含最终字号；仍超出时阻止下载并提示图层。

JPG/PNG 导出只截取工作区，并且不包含任何辅助线。普通 SVG 保持可编辑文字和现有 CorelDRAW 兼容结构；转曲 SVG 使用 `text-to-svg`。红色安全距离虚线始终不会进入这些导出文件。

“宣誓册”产品当前在文字安全检查白名单中。编辑器不显示产品安全距离红色虚线；导出 JSON、图片、SVG，以及保存模板、规格和字体布局时，均不执行文字自动缩小或越界拦截。产品安全距离数据本身仍保留在运行时规格中。白名单由模板库当前产品名称判断，不通过画布尺寸特征推断。

## 产品特殊默认值

当前代码中的“宣誓册”新建规格使用专用默认值：

- 名称：`默认规格`
- 单位：`mm`
- 单面宽：`102.02`
- 单面高：`140.04`
- 左右出血：`58`
- 上下出血：`45.97`
- 背脊宽、背脊出血、最小/最大背脊宽：`0`
- 行间距：`0`

其他产品新建时使用模板库为该产品生成的初始规格；如果没有可用规格，则回退到编辑器默认规格。产品安全距离始终由产品数据提供，不使用上述尺寸默认值代替。
